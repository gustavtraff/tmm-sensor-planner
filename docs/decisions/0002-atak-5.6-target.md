# 0002 – target ATAK-CIV 5.6.0

Date: 2026-10-12. Status: accepted by the repository owner in this project conversation.

## Context

The initial 5.5.0 test target came from an HV Reports/8S package labeled for that
release. It was not a verified server constraint. The owner now reports the actual
phone running ATAK-CIV 5.6.0.12, Data Sync 3.7.4 [5.6.0], HV Reports 1.1.9 [5.5.0]
and TAK Voice 2.1.0 [5.6.0]. A local SDK directory labeled 5.6.0.24 is available
with a host APK, guide, API JAR, tooling and examples. An older SDK was not obtained.

## Decision

Use **5.6.0** as the first plugin API and compatibility target. Use the supplied
**5.6.0.24 SDK** for the initial build investigation. Record the owner's installed
**5.6.0.12 app** as a separate standard-client test target. The sample's plugin API
value is 5.6.0; neither the shared release family nor matching labels prove that a
plugin will load in every build or distribution.

This decision supersedes the active 5.5.0 target in the original project plan.
Support for 5.5.0 is outside the current compatibility claim and requires a separate
SDK/build/test decision. No synchronization or local-privacy verification gate is removed.

## Consequences

- Pin the toolchain from the supplied SDK and build/load a minimal plugin first.
- Verify signing and installation separately for the developer and standard apps.
- Test HV Reports coexistence explicitly because it is still labeled [5.5.0].
- Treat Data Sync and TAK Voice versions as owner-reported, not tested integration support.
- The server version is unknown and is not required for offline development. Obtain
  it from the server administrator before connection, transport and two-client tests.
- Keep SDK files and signing material outside the repository. Preserve the licensing,
  synthetic-data and explicit-sharing requirements.
