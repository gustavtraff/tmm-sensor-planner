# Fixed production-envelope canaries

These metadata-only XML files independently describe the four **synthetic** v18
lab canaries. They were encoded with Python standard-library ElementTree/Base64
from explicit literals, not generated by the Java adapter or codec. The standalone
metadata format is unchanged. These files are not CoT events to import into ATAK.

createdAt `2026-01-01T00:00:00.123456789Z`, updatedAt
`2026-01-01T00:00:10.123456789Z`, absent deployment time, longitude
`-0.234567891234`, true-north bearing reference, imageIncluded `false`.
